# GIT-REPO-FULLSTACK

Practice projects for learning HTML and CSS layouts, forms, grids, dashboards, and login screens.

## Topics covered

- Flexbox and grid layouts
- CSS variables, fonts, and combinators
- Forms, navigation bars, cards, and dashboards

## Running the examples

Open any `.html` file directly in a browser, or use the Live Server extension in VS Code while practicing.

More examples will be added as new layout and component exercises are completed.
